# 04-FUNDAMENTALS : Les briques de base

Ce module construit le vocabulaire et les réflexes sur lesquels tout le reste repose. Chaque thème suit : **problème → explication → exemple → pratique → rappel**.

## Parcours

1. variables
2. scope
3. functions
4. types
5. web basics
6. modules
7. regex

Ne cherche pas la vitesse. Le but est de pouvoir prédire le comportement d’un petit morceau de code avant de l’exécuter.

## Sortie

Tu dois savoir lire un extrait inconnu, expliquer ce qu’il fait, écrire une variante simple et repérer l’hypothèse qui pourrait le faire casser.

## Comment travailler ce module

1. Ouvre d abord le fichier `00_why_*` s il existe : il dit pourquoi le module merite ton temps.
2. Passe le controle de prerequis. Un prerequis manquant se repare en amont, jamais ici.
3. Fais les lecons dans l ordre des numeros. Chaque lecon a un exercice borne : il se rend, il se date.
4. Le grimoire se lit **apres** la pratique, jamais avant : c est une fiche de rappel, pas un cours.
5. Le challenge, puis le boss fight, cochent le module. Sans eux, le module est lu, pas acquis.
