# Contrôle de flux : décider et répéter

Ce sous-module apprend deux gestes fondamentaux : **choisir** une branche (`if / else`) et **répéter** une action (boucles). Il vient après les variables et avant les structures de données ainsi que les fonctions avancées.

## Ordre de travail

1. Lis [`01-control-flow.md`](01-control-flow.md).
2. Fais la pratique [`50-control-flow-minimini.md`](50-control-flow-minimini.md).
3. Passe à Data Basics seulement lorsque tu peux prédire le résultat d'une condition et expliquer quand une boucle s'arrête.

Les exemples utilisent uniquement des nombres, du texte, des booléens et des variables simples. Aucun tableau, objet métier, callback ou framework n'est requis.

## Validation de sortie

- [ ] Je sais expliquer une condition vraie et une condition fausse.
- [ ] Je sais choisir entre `if`, `else if` et `else`.
- [ ] Je sais expliquer le rôle d'un compteur et d'une condition d'arrêt dans une boucle.
- [ ] Je sais repérer le risque d'une boucle qui ne progresse jamais.
