# 00-SOCLE : Niveau 0 : Fondations

Porte d'entrée du palier. Six modules. Tu coches le niveau quand le Boss du palier
est passé, jamais quand les fichiers sont lus.

À la sortie : écrire, lire et raisonner sur du code sans t'y perdre. Livrables : environnement,
plateau de suivi (`PROGRESSION.md`), premières fonctions testées.
