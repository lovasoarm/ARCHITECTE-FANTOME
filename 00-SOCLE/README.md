# 00-SOCLE : Bloc 00 : Fondations

Porte d'entrée du curriculum. Le bloc regroupe six modules principaux et une passerelle Python conditionnelle, utilisée seulement avant les activités qui en ont besoin. Tu le valides à partir
des preuves de sortie déclarées par les README des modules et par la Route 58 ; aucun boss global n'est défini pour les six modules. Lire les fichiers ne suffit jamais.

À la sortie : écrire, lire et raisonner sur du code sans t'y perdre. Livrables : environnement,
plateau de suivi (`PROGRESSION.md`), premières fonctions testées et preuves des modules du Socle.

## Mise en pratique produit : Kintana

Kintana est un cas d’étude pédagogique commun, pas un projet personnel imposé. Pour ce module, applique **la notion réellement enseignée ici** à la mission correspondante dans la [carte des missions Kintana par domaine](../06-ANNEXES-TRANSVERSES/77-FIL-ROUGE-KINTANA/README.md). N’utilise pas automatiquement la FAQ IA : elle est réservée aux activités IA/RAG. Le challenge local de ce module reste la source de la consigne et de ses critères ; cette mise en pratique ne crée ni prérequis, ni gate supplémentaire.
