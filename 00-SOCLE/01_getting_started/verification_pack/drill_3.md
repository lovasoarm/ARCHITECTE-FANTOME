# drill_3 : expliquer a voix haute : pourquoi ce dossier "getting started" ?

Mode de verification : critere binaire du `verification_pack` (voir [criteres.md](criteres.md)).

Duree : 2 minutes chrono, enregistrees.

## Consigne

Enregistre-toi en train d'expliquer, a quelqu'un qui ne connait pas le sujet, quatre points et pas un de plus :

1. le probleme que ce module resout ;
2. la methode, en une phrase ;
3. le chiffre que tu regardes pour savoir si ca marche ;
4. ce que tu fais quand ce chiffre se degrade.

Reecoute-toi une fois. Note chaque terme que tu as employe sans savoir le definir.

## Critere binaire

REUSSI : moins de deux minutes, les quatre points dits dans l'ordre, zero terme non definissable a la reecoute.
NON REUSSI : depassement de duree, un point manquant, ou un terme employe sans definition.
