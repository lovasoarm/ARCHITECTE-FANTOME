# Prérequis du prélude "référentiel"

Temps de lecture ~2 min

Ce prélude n'a pas de prérequis technique : c'est le tout premier document
que tu ouvres après `00-SOCLE/01-GETTING-STARTED/`.

## Prérequis conceptuels

Aucun. Le module peut être abordé par un débutant absolu. La question « pourquoi apprendre JavaScript et les fondations logicielles ? » est une question d’entrée, pas un prérequis à réussir.

## Préparation de l’environnement (déjà couverte dans Getting Started)

- Le dépôt AF est décompressé ou cloné ;
- pour exécuter les exemples JavaScript, utilise le runtime de référence AF **Node.js 22.23.4** (`.nvmrc`) ;
- si l’activité précise un autre outil, suis le `SETUP.md` le plus proche.

Node.js et Git sont des prérequis d’environnement pour certaines pratiques, pas des prérequis mentaux du module. Si tu n’as pas encore l’environnement, travaille d’abord les activités conceptuelles puis reviens à l’exécution prévue.

Rien à installer spécifiquement dans ce module. Ouvre `01-00-why-referentiel.md` et lis.


## Référence du runtime

Le pin `22.23.4` est vérifié dans l'[archive officielle Node.js](https://nodejs.org/en/download/archive/v22.23.4) et dans le [calendrier des releases](https://nodejs.org/en/about/previous-releases), consultés le 1er novembre 2026. Il s'agit du runtime de référence du dépôt, pas d'un prérequis conceptuel pour comprendre ce prélude.
