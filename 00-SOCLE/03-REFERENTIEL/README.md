# MODULE 03 : RÉFÉRENTIEL

> Ce module donne les repères pour comprendre les consignes, suivre sa progression et savoir où chercher. Il n'exige aucune connaissance de programmation. Il ne faut pas confondre ses ressources de référence avec des tests à réussir dès l'entrée.

## Place dans le Socle

Ordre canonique : `01-GETTING-STARTED → 02-PROLOGUE → 03-REFERENTIEL → 04-FUNDAMENTALS → 05-PROBLEM-SOLVING → 06-MINDSET → 01-CADRAGE`.

Les prérequis conceptuels de ce module sont nuls. L'environnement est préparé dans Getting Started. **Tu peux commencer sans savoir programmer.**

Cette première passe ne demande **ni code, ni test, ni API, ni projet, ni transfert entre langages**. Tu peux la terminer avec une note sur papier ou dans un fichier texte.

Les durées affichées dans les fichiers sont des repères locaux. **Aucune durée totale n'est annoncée ici** : le temps réel dépend de la lecture, des exercices et des retours personnels.

## Ressources différées : à ouvrir seulement quand elles deviennent utiles

- [`05-SORTIR_D_UN_PLATEAU.md`](05-SORTIR_D_UN_PLATEAU.md) : aide facultative si une difficulté persiste. Pour un problème d'installation, une consigne incomprise ou une difficulté qui te bloque, demande de l'aide dès que nécessaire ; n'attends jamais un seuil de jours.
- [`07-intemporel_vs_perissable.md`](07-intemporel_vs_perissable.md), [`08-repetition_espacee.md`](08-repetition_espacee.md) et [`09-DEPENDENCY_LEDGER.md`](09-DEPENDENCY_LEDGER.md) : références à consulter après Fundamentals, au moment où un concept ou une dépendance est réellement étudié.
- [`02-micro_quiz_15_mots.md`](02-micro_quiz_15_mots.md) : quiz de rappel différé, uniquement après l'étude des notions correspondantes.
- [`06-where_you_stand.md`](06-where_you_stand.md) : auto-positionnement après une ou plusieurs preuves réelles ; jamais avant d'avoir fait une tâche.
- [`95-challenge.md`](95-challenge.md) : challenge papier facultatif, à faire **après la première pratique indépendante de Fundamentals**. Il ne conditionne ni l'entrée dans Fundamentals ni la poursuite de la route.
- [`90-grimoire.md`](90-grimoire.md) : mémo de consultation, pas une étape obligatoire de la première passe.
- [`ATELIER-CONSOLIDATION.md`](ATELIER-CONSOLIDATION.md) et [`SETUP.md`](SETUP.md) : à ouvrir uniquement lorsqu'une activité pratique ultérieure les demande ; ils ne sont pas nécessaires pour lire ce module.

Un terme inconnu signifie simplement « pas encore étudié ». Tu peux le laisser de côté et continuer la route canonique.

## Comment travailler ce module

1. Lis les cinq ressources de première passe dans l'ordre. Ne cherche pas à mémoriser la liste des compétences.
2. Note une seule question, un mot nouveau ou une chose que tu as comprise. Une phrase suffit.
3. Continue vers [Fundamentals](../04-FUNDAMENTALS/README.md) lorsque cette note est faite. **Aucun challenge, quiz, transfert, auto-positionnement, atelier ou exercice Kintana n'est requis pour y entrer.**
4. Reviens aux ressources différées uniquement lorsque la route ou une leçon les rend utiles. Avant une activité exécutable, lis son `SETUP.md` si cette activité le demande ; cette règle ne s'applique pas à la lecture du Référentiel.
5. Le challenge 95 peut être fait après la première pratique indépendante de Fundamentals. Le grimoire reste un aide-mémoire facultatif.

## Ce que ce module produit dans ton dossier local de preuves

À la sortie, tu dois savoir où trouver les consignes, comment signaler une lacune et comment distinguer une connaissance lue d'une compétence démontrée. Une courte note datée dans ton journal local ou dans `PREUVES/00-SOCLE/03-REFERENTIEL.md` suffit. Aucun projet personnel, dépôt Git ou logiciel exécutable n'est attendu dans ce module.

- [ ] Je peux continuer vers Fundamentals sans avoir réalisé le challenge 95, un quiz, un transfert, un atelier ou une mission Kintana.

## Kintana : cas d'étude différé, pas une mission d'entrée

Kintana est un cas d'étude fictif commun, jamais un projet personnel imposé. **Aucune mission technique Kintana n'est demandée pendant la première passe du Référentiel ni avant Fundamentals.** Une seule activité Kintana facultative est conservée dans [`06-where_you_stand.md`](06-where_you_stand.md) ; elle n'est accessible qu'après les prérequis des étapes 3, 4, 5 et 8 de la [Route 58](../../06-ANNEXES-TRANSVERSES/58-ROUTE-APPRENANT-COHERENTE.md). Elle ne crée aucune gate de progression.
