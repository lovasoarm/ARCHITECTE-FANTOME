# 05 : Journal hebdo

Temps de lecture ~2 min

Fin de la première semaine, puis chaque dimanche. Fichier unique dans **ton** fil rouge :
`JOURNAL.md`. Pas dans ce dépôt.

Chaque entrée, 8 lignes max :

```text
semaine:
heures réellement faites (pas prévues) :
un geste qui a marché :
un geste que je ne referai pas :
un chiffre (test, p95, euros, lignes) :
prochaine séance (date + fichier exact) :
```

Sans chiffre, ce n'est pas un journal, c'est un mood. Le lint personnel : 2 semaines
sans entrée → tu rouvres [09-ROUTE-SURVIE.md](../00-SOCLE/01-GETTING-STARTED/09-ROUTE-SURVIE.md)
avant d'ouvrir un module neuf.
