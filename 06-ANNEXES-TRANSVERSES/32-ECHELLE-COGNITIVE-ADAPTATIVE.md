# 32 : Échelle cognitive adaptative AF

AF ne doit pas seulement augmenter le volume de connaissances. Il doit augmenter la **qualité du raisonnement demandé**.

## Les dix niveaux

| Niveau | Nom          | L’apprenant doit pouvoir…                                            | Échec typique                    |
| ------ | ------------ | -------------------------------------------------------------------- | -------------------------------- |
| L0     | Recall       | restituer un fait ou une définition utile                            | récitation sans compréhension    |
| L1     | Explain      | expliquer un mécanisme causal                                        | vocabulaire sans mécanisme       |
| L2     | Apply        | appliquer un mécanisme dans un cas connu                             | recette copiée                   |
| L3     | Diagnose     | isoler une cause parmi plusieurs                                     | corrélation = cause              |
| L4     | Discriminate | distinguer plusieurs solutions plausibles                            | fausse équivalence               |
| L5     | Decide       | choisir sous contraintes explicites                                  | optimiser un seul axe            |
| L6     | Defend       | défendre ou rejeter une décision devant contradiction                | argument d’autorité              |
| L7     | Revise       | changer d’avis lorsqu’une preuve invalide une hypothèse              | rationalisation a posteriori     |
| L8     | Transfer     | conserver l’invariant dans un contexte nouveau                       | transport aveugle d’une solution |
| L9     | Govern       | définir des garde-fous permettant à d’autres de décider correctement | héroïsme individuel              |

## Règle de progression

Un sujet n’est **pas maîtrisé** parce que L0–L2 sont réussis. Une compétence CORE doit atteindre au minimum L5, et les compétences Staff critiques doivent atteindre L6–L9 sur plusieurs contextes.

Le niveau demandé doit varier au fil du parcours. Une série de checkpoints qui reste au même niveau cognitif est considérée comme une **dette pédagogique**, même si les questions changent.

## Mesure obligatoire

Pour chaque épreuve CORE, le formateur ou l’auto-évaluateur doit pouvoir répondre à quatre questions :

1. Quel niveau cognitif est testé ?
2. Quelle hypothèse peut être fausse ?
3. Quelle observation pourrait faire changer d’avis ?
4. Quel transfert est suffisamment éloigné pour empêcher une copie de recette ?

## Règle Staff

Une réponse purement descriptive ne peut jamais obtenir la certification Staff. Il faut au minimum une chaîne observable :

**hypothèse → décision → conséquence → mesure → contradiction → révision → transfert**.
