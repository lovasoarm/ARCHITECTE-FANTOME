# 51 - TERRAIN STARTER PACK

Le but est de sortir du dépôt sans attendre d'avoir "10 ans d'expérience".

## Option A - utilisateurs externes

Commencer avec 3 à 10 personnes hors du projet.

Mesurer :

```text
activation
temps de tâche
erreurs
abandon
feedback
demandes de changement
```

## Option B - open source

Commencer petit :

```text
documentation
reproduction de bug
test
small fix
issue
pull request
```

La taille de la contribution compte moins que le fait qu'un tiers puisse la discuter ou la refuser.

## Option C - petite mission

Exemples :

```text
association
petite entreprise
club
communauté
projet étudiant externe
```

Faire signer ou confirmer le périmètre lorsque nécessaire.

## Option D - partenaire

Un partenaire peut fournir :

```text
brief
contrainte
retour
priorité
acceptation / refus
```

## Sortie obligatoire

Après l'expérience :

```text
niveau T0/T1/T2/T3/T4
ce que cela prouve
ce que cela ne prouve pas
mesures
décisions
changements
```

## Sécurité

Ne jamais publier de données sensibles, secrets, informations personnelles ou code privé
sans autorisation.
