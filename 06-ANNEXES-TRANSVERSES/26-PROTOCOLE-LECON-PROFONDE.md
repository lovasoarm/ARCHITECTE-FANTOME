# 26 : PROTOCOLE DE LEÇON PROFONDE

> Ce protocole s'applique aux leçons CORE existantes. Il n'oblige pas à réécrire tous les fichiers : il change la manière de les traverser.

## Avant la leçon : prédiction

Ferme le document et réponds :

- quel problème cette leçon devrait-elle résoudre ?
- quelle mauvaise intuition vas-tu probablement avoir ?
- quelle observation pourrait te faire changer de modèle ?

Une réponse courte suffit. Elle doit être datée avant la lecture.

## Pendant : modèle causal

Ne note pas une définition uniquement. Extrais :

```text
CAUSE → MÉCANISME → EFFET → SIGNAL OBSERVABLE
```

Puis :

```text
INVARIANT
CONDITION DE VALIDITÉ
LIMITE
CONTRE-EXEMPLE
TRADE-OFF
```

## Après : fermeture du document

Sans revoir la leçon :

1. explique le mécanisme avec tes propres mots ;
2. donne un exemple nouveau ;
3. donne un contre-exemple ;
4. donne une situation où la bonne pratique devient mauvaise ;
5. propose une observation qui te ferait changer d'avis.

## Après la pratique

Le livrable doit contenir, lorsque le sujet s'y prête :

- décision ;
- option rejetée ;
- preuve ;
- coût créé ;
- condition de révision ;
- transfert.

## Anti-mémorisation

Une réponse correcte obtenue uniquement par restitution ne ferme pas la compétence. Elle ferme uniquement la couche de vocabulaire.

## Compression intelligente

Si une leçon est longue :

- lire intégralement lors de la première exposition ;
- extraire les invariants et les décisions ;
- revenir ensuite par recherche ciblée ;
- réactiver par rappel et transfert plutôt que relire tout le document.

La richesse documentaire reste disponible ; l'effort cognitif est déplacé de la lecture répétée vers la reconstruction.
