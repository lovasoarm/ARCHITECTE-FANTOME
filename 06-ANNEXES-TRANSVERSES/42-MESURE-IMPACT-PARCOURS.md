# 42 : MESURE D'IMPACT DU PARCOURS

Ce protocole mesure la valeur du parcours sans fabriquer de taux de réussite, d'employabilité ou de causalité. Les données sont volontaires, minimisées et présentées comme des observations, jamais comme une garantie de carrière.

## 1. Ce qu'on peut mesurer honnêtement

### Départ

- niveau auto-déclaré et preuves disponibles ;
- temps disponible réel ;
- objectifs poursuivis ;
- expérience de projet et d'équipe ;
- accès au terrain réel, quand il existe.

### Pendant le parcours

- temps jusqu'à la première preuve visible ;
- blocs CORE terminés ;
- blocages récurrents ;
- artefacts réellement produits ;
- feedback de reviewers ;
- écarts entre temps prévu et temps réel.

### Après / externe

- projet publié ou maintenu ;
- contribution open source ;
- mission, stage, entretien, emploi ou évolution de rôle **auto-déclaré** ;
- preuves terrain T1–T4 ;
- feedback qualitatif d'utilisateurs, pairs ou mainteneurs.

## 2. Ce que ces données ne permettent pas de conclure seules

Ne pas transformer une cohorte en promesse de placement, de salaire, de promotion ou de performance professionnelle. Les biais possibles incluent auto-sélection, survivorship bias, faible taille d'échantillon, niveau initial différent, accès inégal aux opportunités, contexte géographique et absence de groupe contrôle.

## 3. Mesure minimale

Une cohorte ou un apprenant peut produire une fiche synthétique :

| Mesure | Baseline | Point suivant | Source |
|---|---|---|---|
| Première preuve visible (date) | | | journal / dépôt |
| CORE complété | | | progression |
| Artefacts publiables | | | portfolio |
| Review externe obtenue | | | lien/trace |
| Preuves terrain T0–T4 | | | pont terrain |
| Blocage principal | | | journal |
| Temps réel / prévu | | | journal |

## 4. Cadence

- **J0** : baseline ;
- **fin CORE** : rétrospective ;
- **3 à 6 mois** : suivi volontaire ;
- **12 mois** : suivi volontaire ;
- au-delà : uniquement si l'apprenant souhaite conserver la trace.

Aucun suivi quotidien obligatoire. Aucune collecte de contenu privé ou de données client.

## 5. Lecture par famille Staff

Les preuves S1–S6 sont qualifiées par l'artefact réel, pas par un score unique. Le reviewer note ce qui est démontré, ce qui est simulé et ce qui reste à obtenir sur le terrain.

## 6. Règle statistique

Si le nombre d'observations est faible ou le contexte hétérogène, écrire explicitement **donnée insuffisante**. Une amélioration observée peut soutenir une hypothèse d'utilité ; elle ne prouve pas que le curriculum en est la cause.

**Temps CORE ajouté : 0 h.**
