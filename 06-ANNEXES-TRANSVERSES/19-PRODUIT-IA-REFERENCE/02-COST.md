# Cost model

Le produit sépare le coût de retrieval local du coût variable du provider LLM.

Formule pédagogique :
`coût_mensuel = appels × coût_par_appel + stockage + observabilité`

Le plafond doit être défini dans `PREUVES/IA-EN-PROD.md` du projet
apprenant. Aucun prix fournisseur n'est figé ici : les prix réels sont relevés,
datés et sourcés dans le module cloud.
