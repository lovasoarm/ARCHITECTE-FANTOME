Le module utilise le cas d’étude pédagogique commun [Kintana](../../06-ANNEXES-TRANSVERSES/77-FIL-ROUGE-KINTANA/README.md). Pour ce bloc, la mission centrale est **frontière de confiance** : Applique la notion à une route Kintana utilisée par demandeur, agent ou superviseur. Définis la menace, impose le contrôle côté serveur et écris des tests négatifs avec deux comptes distincts. Le module est validé par une preuve reproductible, un cas limite et une explication du compromis : Un utilisateur ne lit/modifie pas la ressource d’un autre ; le refus ne révèle pas de donnée privée ; l’événement sensible est auditable.
