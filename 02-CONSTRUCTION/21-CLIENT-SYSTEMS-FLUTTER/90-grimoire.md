> **SCÈNE CRAZYDEVS : Rasengan :** un bon cache ressemble à un jutsu préparé : il accélère l’action, mais il ne change pas magiquement la réalité du monde extérieur.

# Grimoire : Client Systems

| Terme         | Définition                                            | Code / signal                | Analogie CrazyDevs                          |
| ------------- | ----------------------------------------------------- | ---------------------------- | ------------------------------------------- |
| State         | Information qui influence le rendu ou le comportement | variable / store / snapshot  | état du combattant                          |
| Cache         | Copie temporaire d’une donnée                         | TTL / version / key          | plan de secours de Scofield                 |
| Idempotence   | Répéter une opération produit le même effet voulu     | request-id / clé idempotence | même jutsu lancé deux fois, pas deux dégâts |
| Offline-first | Le système a un comportement défini sans réseau       | queue locale / sync          | tunnel sans garde au bout                   |
