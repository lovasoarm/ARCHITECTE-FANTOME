# HORS SCOPE DU CURRICULUM PRINCIPAL

-> ~5 min

Ce dossier n'est pas dans ta progression normale.

```text
NIVEAU : algorithmique compétitif
PUBLIC : dev qui prépare des entretiens LeetCode/hard ou des concours de programmation
PRÉREQUIS : avoir fini 02-CONSTRUCTION/06-DATA-STRUCTURES COMPLET + 02-CONSTRUCTION/07-ALGORITHMS COMPLET
```

Ce que tu trouveras ici (Union-Find, Fenwick Tree, Suffix Array) ne t'est pas nécessaire pour :

- passer un entretien dev standard
- construire les 19 mini-projets du curriculum
- finir les modules `02-CONSTRUCTION/12-TYPESCRIPT` a `05-MAITRISE/03-EDGE-CASES`

Ces structures existent dans les systèmes à très haute performance (bases de données, compilateurs, moteurs de recherche). En prod, tu ne les réimplémenteras probablement jamais : tu utiliseras une lib qui le fait. Mais les comprendre change ta façon de lire la complexité d'un système.

**Ne bloque pas ta progression pour ça.**
Finis `02-CONSTRUCTION/07-ALGORITHMS` en entier. Reviens ici si tu veux aller plus loin.
