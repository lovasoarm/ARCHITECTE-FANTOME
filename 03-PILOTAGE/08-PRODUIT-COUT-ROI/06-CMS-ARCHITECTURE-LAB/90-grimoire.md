> **SCÈNE CRAZYDEVS : cache ninja :** un CMS ne devient pas magique parce qu’on l’appelle headless.

# Grimoire : CMS Architecture

| Terme      | Définition                            | Signal                 | Analogie CrazyDevs                   |
| ---------- | ------------------------------------- | ---------------------- | ------------------------------------ |
| CMS couplé | contenu + présentation fortement liés | front dépendant du CMS | prison avec une seule sortie         |
| Headless   | contenu exposé via API                | front libre            | tunnel séparé du bâtiment            |
| Lock-in    | coût croissant de sortie              | migration difficile    | porte qui se verrouille derrière toi |
| Preview    | voir un contenu avant publication     | workflow éditorial     | répétition générale                  |
