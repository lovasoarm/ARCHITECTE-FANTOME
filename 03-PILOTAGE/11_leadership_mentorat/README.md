# 03-PILOTAGE/11_leadership_mentorat : influence sans autorité

> Mode de vérification des exercices de ce module : défense orale enregistrée contre grille ([../../05-MAITRISE/08_maitrise_staff_engineer/challenge.md](../../05-MAITRISE/08_maitrise_staff_engineer/challenge.md)).

Temps de lecture ~4 min

## Ce que c'est

Le module qui travaille le seul levier réel d'un Staff Engineer : d'autres gens décident mieux après lui avoir parlé. Revue de code qui transmet un critère, mentorat qui laisse une trace, standard qu'un outil vérifie, traduction d'une décision par public, et aveu d'ignorance qui renforce au lieu d'affaiblir.

- [01_mentorat_solo.md](01_mentorat_solo.md) : le mode solo, mentoré fictif documenté, trois productions à réviser.

## Comment lire ce module

Dans l'ordre affiché ci-dessus, pas dans l'ordre des numéros de fichiers : le grimoire porte le numéro 01 pour raisons historiques, il se lit à la fin.

## Signal que tu es prêt pour la suite

Les trois drills du [verification_pack](verification_pack/criteres.md) sont REUSSI, et tu as écrit une revue à trois niveaux avec un risque nommé, une note d'une page sans jargon avec des chiffres sourcés, et tu as tenu un standard face à trois oppositions sans t'appuyer sur une autorité hiérarchique.
