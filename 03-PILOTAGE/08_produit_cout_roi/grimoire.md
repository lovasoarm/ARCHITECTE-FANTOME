# GRIMOIRE : PRODUIT, COÛT, ROI

| Règle | Analogie 1 | Analogie 2 |
| --- | --- | --- |
| Trois nombres : valeur, coût, risque. | un devis de travaux | un bilan de santé |
| « Ne rien faire » est toujours une option du tableau. | rester chez soi | garder sa vieille voiture |
| Un nombre sans source est une opinion. | un prix sans étiquette | une citation sans auteur |
| Point mort = coût / gain mensuel. | un panneau solaire | un abonnement contre des tickets |
| Refactorer du code jamais modifié n'a pas de point mort. | repeindre une cave murée | réviser une voiture au garage à vie |
| Une dette sans intérêt chiffré n'est pas une dette. | un prêt sans taux | un ardoise sans montant |
| Le déclencheur est une métrique, pas une humeur. | un seuil d'alarme | une date de péremption |
| Les coûts déjà dépensés ne décident de rien. | un billet non remboursable | un repas déjà payé |
| Le refus s'acte, le coût de l'attente s'écrit. | un accusé de réception | un constat amiable |
| Il existe presque toujours une version à 20 %. | une roue de secours | un pansement avant l'opération |
