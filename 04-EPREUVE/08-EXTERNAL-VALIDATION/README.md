# EXTERNAL VALIDATION

## But

Une preuve importante doit, à un moment donné, rencontrer quelque chose que le candidat
ne contrôle pas entièrement.

## Modes

```text
R1 - REVIEW EXTERNE
un tiers lit et conteste les preuves

R2 - OPEN SOURCE
un mainteneur ou une communauté accepte / refuse un changement

R3 - UTILISATEURS EXTERNES
des personnes hors du projet utilisent le système

R4 - MISSION / CLIENT
un tiers possède un objectif, une contrainte ou une capacité de refus

R5 - PRODUCTION
un système vivant est utilisé, mesuré et maintenu
```

## Protocole de review

```text
1. brief
2. artefacts
3. revue aveugle
4. objections
5. questions business
6. décision finale
7. diff initial / final
```

## Preuve

```text
reviewer
rôle
relation avec l'auteur
date
ce qu'il a vu
findings
décision initiale
décision finale
```

## Règle

Une seconde personne n'est pas automatiquement un reviewer indépendant.
La relation et les conditions de revue doivent être déclarées.
