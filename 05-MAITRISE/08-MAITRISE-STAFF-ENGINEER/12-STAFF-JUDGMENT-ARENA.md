# 12 : Staff Judgment Arena

Le niveau Staff n'est pas la capacité à trouver une réponse brillante. C'est la capacité à choisir entre plusieurs réponses plausibles, puis à vivre avec leurs conséquences.

## Manche A : ambiguïté

Le briefing doit être incomplet volontairement. Produire :

1. les inconnues ;
2. les hypothèses ;
3. les personnes affectées ;
4. le minimum de décision réversible ;
5. ce qui doit attendre.

## Manche B : désaccord légitime

Deux options techniquement défendables sont proposées. Le candidat doit faire converger la décision sans invoquer son titre, avec une note de décision lisible par des personnes non techniques.

## Manche C : meilleure idée externe

Une proposition provenant d'un pair moins expérimenté, d'un contradicteur ou d'un utilisateur doit être intégrée lorsqu'elle est meilleure. La preuve attendue n'est pas « je suis humble » mais une modification observable du dossier.

## Manche D : coût politique

Le candidat doit recommander une action techniquement correcte mais socialement coûteuse : abandon, réduction de scope, gel d'une fonctionnalité ou migration. La note doit expliciter le coût humain/organisationnel accepté.

## Manche E : décision sans IA parfaite

L'IA est volontairement partiellement fiable. Le candidat doit décider ce qui peut être délégué, ce qui doit être vérifié, et quand arrêter l'automatisation.

## Pass condition

Chaque manche doit laisser une trace dans `PREUVES/STAFF-JUDGMENT.md` avec :

`contexte → options → décision → coût accepté → signal de révision → résultat → révision éventuelle`.
