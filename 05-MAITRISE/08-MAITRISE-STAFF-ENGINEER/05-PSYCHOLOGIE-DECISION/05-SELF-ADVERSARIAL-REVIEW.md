# SELF-ADVERSARIAL-REVIEW : construire le meilleur dossier contre soi

Sur une décision réelle, écris :

1. ma décision ;
2. pourquoi je la préfère ;
3. ce que je gagne ;
4. ce que je perds ;
5. le meilleur argument contre moi ;
6. la donnée qui me ferait changer ;
7. mon biais probable ;
8. ce que je minimise peut-être ;
9. ce que le contradicteur voit probablement mieux ;
10. l'option inverse défendue honnêtement pendant cinq minutes.

## Test

Après la défense de l'inverse, réécris la décision sans te référer à ton premier texte. Compare les deux versions.
