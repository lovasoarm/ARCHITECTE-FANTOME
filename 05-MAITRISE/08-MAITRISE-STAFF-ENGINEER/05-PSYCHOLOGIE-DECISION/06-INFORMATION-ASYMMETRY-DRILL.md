# INFORMATION-ASYMMETRY-DRILL : décider avec information incomplète

## Manche

À t0, tu reçois uniquement le brief initial. Tu dois écrire :

- faits connus ;
- hypothèses ;
- inconnues ;
- décision réversible ;
- décision irréversible ;
- information qui pourrait faire changer d'avis.

À t+5, t+15 puis t+30 minutes, de nouvelles informations apparaissent, dont au moins une contradiction.

## Preuve

Conserve les quatre états `je savais / je croyais / je supposais / je décidais`.

## Test

Le correcteur interdit toute utilisation d'information révélée après la décision initiale pour juger la qualité de cette décision. C'est le **decision attribution error check**.
